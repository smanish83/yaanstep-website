# Yaanstep website

Static site for yaanstep.com. Plain HTML and CSS. Small optional scripts power the interactive pages (`try-it.html`, `time-calculator.html`); every page still works with JavaScript off. No cookies, no trackers.

- Pages: `index.html`, `how-it-works.html`, `pricing.html`, `team.html`, `testers.html`, `try-it.html`, `time-calculator.html`, `privacy.html`, `terms.html`, `accessibility.html`
- Styles and logo: `assets/`
- Legal pages are team-written drafts; no lawyer has reviewed them.
