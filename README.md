# Yaanstep website

Static site for yaanstep.com. Plain HTML and CSS. Small optional scripts power the interactive pages (`try-it.html`, `time-calculator.html`, `sprouts.html`); every page still works with JavaScript off. No cookies. Visits are counted with Umami Cloud (cookie-free, no personal data; never under automated tests, Do Not Track or Global Privacy Control, and never on the Teens pages): see `assets/analytics.js` and the "Counting visits" part of `privacy.html`.

- Pages: `index.html`, `how-it-works.html`, `pricing.html`, `team.html`, `testers.html`, `try-it.html`, `time-calculator.html`, `sprouts.html`, `privacy.html`, `terms.html`, `accessibility.html`
- Styles and logo: `assets/`
- Legal pages are team-written drafts; no lawyer has reviewed them.
